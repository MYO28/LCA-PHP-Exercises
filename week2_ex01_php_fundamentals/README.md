# LCA PHP Exercises

This repository contains backend PHP scripts completed during the Backend Web Development course at LCA.

## Repository Structure

## Exercise Summary

- **intro.php:** Fundamental PHP syntax, dynamic greetings, mathematical calculations, date output, and random number generation embedded in HTML.
- **variables.php:** Data types, type checking with `gettype()`, explicit conversion with `intval()`, personal bio generation, and a dynamic BMI calculator with an interactive status table.
- **scope.php:** Demonstration of PHP variable scope including `global`, local, and persistent `static` function variables.
- **casting.php:** Explicit PHP type casting using `(int)`, `(float)`, `(string)`, and `(bool)` primitives.
